One home, three ways in

The same registry and session history sit behind every surface, under ~/.quiver on your machine.

swe

Terminal

Launch any agent by name or alias, resume a session from any of them, and keep skills and MCP servers in sync. Arguments pass straight through to the real tool.

Quiver.app

Mac app

Usage, limits and sessions at a glance, plus accounts, skills, AGENTS.md and MCP servers, without remembering commands. Widgets included.

swe remote

Phone

Watch and steer running sessions from your phone. A small hub on your machine talks to the web app and iOS app over your tailnet, so no third party stores your transcripts.

Everything your agents scatter, in one place

quiver reads each tool's own logs and configs read-only and shells out to the real binaries. It never wraps or replaces them.

Sessions

One time-sorted list of recent sessions across 21 agents. swe session use 3 moves you into the folder and resumes it.

Usage and quotas

Model usage from every tool's logs, and the remaining quota with a reset countdown for the harnesses you star.

Skills

Find every SKILL.md across harness roots, then link, move or catalog them so each agent sees the same set.

MCP sync

Compare, validate and copy MCP server definitions between tools, instead of pasting the same block into five configs.

Reports

Daily and weekly summaries of what your agents did, with a cost preview before anything runs and follow-ups you can launch later.

Providers

API keys and metadata for 27 built-in LLM providers plus your own, kept in one place for every harness.

Works with the agents you already use

swe harness discover scans your PATH and registers anything it recognises.

Up and running in a minute

The core CLI uses only the Python standard library. Nothing else gets installed.

1

Install with pipx (or Nix).

$ pipx install git+https://github.com/c-wenlong/quiver.git
2

Run the setup wizard. It finds your agents, providers, MCP servers and skills.

$ swe setup
3

Pick up where you left off, in any agent.

$ swe session -i
